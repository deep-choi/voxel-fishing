# 버들못 · 복셀 좌대 낚시

큰 저수지에 좌대 8개, 좌대마다 낚싯대 설치 자리 3개가 있는 1인칭 복셀 낚시 게임.

## 실행

웹 접속: https://voxel-fishing-choi.web.app/

`npm run deploy` — 프로덕션 빌드 후 게임 전용 Firebase Hosting으로 배포.
배포 설정과 낚시터별 주소는 [Hosting 안내](docs/hosting.md)를 참고하세요.

GitHub: https://github.com/deep-choi/voxel-fishing (비공개).

Google 로그인과 닉네임 설정 후 기본 맵 버들못에 자동 입장합니다. 현재 버들못만 개방하며, 나머지 세 낚시터는 구현을 유지한 채 입장을 막았습니다. 낚시터마다 현재 인원 / 정원을 표시하며 정원은 24명입니다. 만석이면 입장을 막습니다.

채팅은 화면 왼쪽 아래에 표시됩니다. `Enter`로 입력·전송하고 `Esc`로 낚시에 돌아갑니다. 메뉴의 계정·낚시터 채팅·온라인 랭킹은 각각 분리했으며, `L`은 온라인 랭킹을 엽니다.

`npm run dev` — 접속 주소는 터미널에 표시됩니다.
`npm run build` — 타입 검사와 빌드.

기본은 일반 낚시 모드입니다. 줄 굵기·채비 예민함·바늘 크기·미끼에 따라 입질 어종, 씨알, 바늘 걸림과 이탈이 달라집니다. 가는 줄은 입질에 유리하지만 대물 파이팅에서 잘 끊어집니다. 큰 바늘은 잔챙이 입질을 줄이고 대물 유지력을 높입니다. 기능 확인용 빠른 모드는 `?fast=1`로 켭니다.

## 조작

- 마우스: 둘러보기 / WASD: 이동
- E: 가까운 받침틀에서 대 꺼내 들기 / 손에 든 대 거치 / 거치한 대 다시 들기
- 0: 손에 든 대 거치 / 1·2·3: 가까이 거치한 대를 번호로 집어 들기
- F: 가까운 낚싯대 회수 (물에 있는 채비를 걷고 가방에 넣음)
- 가방(I)의 낚싯대: 꺼내기(지금 좌대의 빈 받침대 자리) / 펼친 대마다 회수 버튼
- 좌클릭 길게 누른 뒤 놓기: 앞치기 (채비를 손에 쥐었다 놓으며 대를 살짝 들어 올림. 머리 위로 휘두르지 않음) / R: 채비 걷기
- 좌클릭·우클릭 또는 Space: 챔질 = 대를 들어 올리는 동작. 고기가 안 걸리면 채비가 물 밖으로 나와 바로 회수할 수 있음
- 물고기가 걸리면 좌클릭: 대 세우기 / 우클릭: 대 숙이기
- 낚싯대는 낮은 거치대에 놓이며 초릿대가 수면 가까이에 옵니다.
- 걸린 물고기는 복셀로 표시되고, 찌에서 내려온 목줄과 바늘이 입에 연결됩니다. 지친 고기를 발 앞까지 끌어오면 바늘을 문 채 수면으로 떠올라 끌려오고, 물 밖으로 들려 손에 잡힙니다.
- M: 좌대 지도와 이동 / C: 채비 / Tab: 살림망 / Z: 망원
- G: 집어 떡밥 / B: 상점 / V: 도감 / J: 어종별 개인 기록
- I: 가방 (보유 장비, 미끼·집어제, 떡밥 재료와 배합)
- 물고기를 잡은 뒤 E: 보관 / R: 놓아주기 (배스·블루길은 수매)
- 핫바 1~3: 낚싯대 / 4: 집어 떡밥
- Q: 일일 의뢰·업적 / T: 대회 / K: 기술 / O: 설정
- Esc 또는 오른쪽 위 메뉴 버튼: 메뉴 (레벨·돈·날씨 상세와 장비·활동·기록 분류, 조작법). 받을 보상·기술 포인트는 메뉴 버튼 배지로 알림
- 화면에는 조준점·핫바·경험치 줄·시계·메뉴 버튼만 항상 보이고, 키 안내·캐스팅 힘·장력계·찌 확대·대회 순위는 필요할 때만 나타남
- 모바일: 설정의 터치 조작(자동/켜기/끄기). 가로 화면 기준, 입장하면 전체 화면(안드로이드). 왼쪽 아래 엄지로 걷기, 화면 끌기로 시점. 오른쪽 아래 버튼은 지금 할 수 있는 동작만 보인다: 큰 버튼이 던지기 → 챔질(누른 채 버티면 그대로 세우기) → 세우기로 바뀌고, 걸었을 때만 숙이기, 기다릴 때만 걷기·거치·망원. 휴대폰에서는 메뉴 패널이 화면을 꽉 채우고 오른쪽 위 ✕로 닫는다. 노치·홈 막대 영역은 피한다 (src/ui/mobile.css)

## 러시안피싱4식 시스템 (`game/`)

- `environment.ts`: 게임 시간(실제 48분 = 하루), 날씨·기온·수온·기압 → 어종별 입질 배수
- `items.ts`: 등급(일반~전설), 뜰채(무게 한계), 살림망(마릿수 한도 20·50·100), 어종별 시세·금지 체장·교란종 수매가
- `modifiers.ts`: 시간·기술·마모가 낚시 규칙에 주는 보정값. `main.ts`가 채우고 `fishing.ts`가 읽는다
- `economy.ts`: 오늘의 시세, 일일 의뢰 3개, 업적
- `tournament.ts`: 참가비·상금이 있는 대회. 지금은 봇이 다른 참가자를 대신한다
- `skills.ts`: 레벨당 1포인트, 5갈래 기술
- 손맛: 낚싯대마다 휨새(경질·연질)가 달라 힘이 약하면 초릿대만, 강하면 허리까지 휜다. 버티지 않으면 고기가 대를 끌고 들어가고, 바늘털이 때 초릿대·화면이 떨리며 모바일은 진동한다. 걸리는 순간 대가 '턱' 휘고, 헛챔질하면 채비가 물을 털며 날아온다
- 찌맞춤: 기본 1목 (찌톱 10마디 중 한 마디만 물 위). `Fishing.trimNotches`로 바꾼다
- 고기 힘: 실제보다 1.8배 세게. 큰 고기는 더 지쳐야 뜨고, 발 앞에서 대를 세운 채 버텨야 들린다 (붕어 0.3kg 약 0.5초, 잉어 3kg 약 3초). 끌어내는 연출도 무거울수록 길고 대가 깊게 휜다
- 야광찌: 어두울수록 찌톱 끝 케미 불빛(케미 연두·전자찌 빨강)이 크게 번진다. (챔질·원줄 울음 소리는 비워 둠: 나중에 녹음 소리로)
- 찌: 붕어는 예신(찌톱 깜빡) → 멈춤 → 확실한 본신(몸통이 드러날 만큼 쭈욱 올리거나, 가끔 쭈욱 빨아들임). 잉어·메기·쏘가리·배스는 쭈욱 빨아들인다. 집어가 될수록 찌가 가끔 들썩이고, 비·흐린 날은 물결이 커진다
- 장비 마모: 파이팅 장력만큼 원줄·낚싯대가 닳고(종류별로 공유), 상점 수리 탭에서 고친다
- 관리동: 다리 입구 물가의 수상 마당. 왼쪽 낚시점(B, 장비·미끼 구매), 오른쪽 어시장(N, 물고기 판매·오늘의 시세). 계산대 앞에서 E 또는 단축키로 열고, 멀리 있으면 M 지도 → 관리동으로 이동
- 살림망(Tab)은 보관과 방생만. 배스·블루길은 잡은 자리에서 수매
- 상품명: 실제 국내 판매 브랜드(바낙스·은성·해동·금호조침·선라인·토레이·루미카·경원·마루큐·토코·오뚜기·농심·롯데칠성). `data.ts`·`items.ts`의 name만 바꾸면 교체된다. 출시 전 상표 사용 허락 필요

설치한 낚싯대는 다른 좌대로 이동해도 그 자리에 남아 각자 입질을 기다립니다.
장비, 미끼 재고, 돈, 경험치, 조과, 살림망, 설치 위치와 채비는 브라우저에 저장됩니다.
다시 접속하면 설치한 낚싯대는 채비를 걷은 상태로 복원됩니다.

## 싱글 진행

기본 낚싯대 3대와 미끼, 500원으로 시작합니다. 붕어·잉어·향어·블루길을 잡아 도감을 채우고 경험치를 얻습니다.
보관한 물고기는 살림망에서 판매하고, 상점에서 미끼와 낚싯대·찌·바늘을 구매할 수 있습니다.
어종은 붕어·잉어·향어·메기·동자개·가물치·쏘가리·배스·블루길 총 9종입니다. 몸통, 지느러미, 수염, 무늬와 입질을 다르게 구성했습니다.
미끼는 지렁이·옥수수·민물새우·곡물떡밥·글루텐떡밥·어분떡밥이며, 미강·옥수수가루·새우분·어분·글루텐분으로 떡밥을 배합합니다.
좌대는 갈대밭·버드나무·수초밭·황토턱·골자리·물골·제방·수문 이름을 사용합니다.
UI는 픽셀 글꼴, 각진 돌·목재 패널, 아이템 슬롯과 직접 만든 픽셀 아이콘을 사용합니다.
좌대 1~2번은 얕은 붕어 포인트, 안쪽 좌대는 잉어·향어를 위한 깊은 포인트입니다.
개인 기록은 어종별 전체 / 이번 주 최대 길이 순위입니다.

물고기 디자인은 `game/fishArt.ts`에 어종마다 도트로 찍은 옆모습 그림(글자 한 칸 = 한 도트)으로 있습니다. 3D 복셀 모델과 도감 아이콘이 같은 그림을 씁니다. `npm run dev` 후 `/fishlab.html`에서 9종을 한 화면에 비교할 수 있습니다(`?spin=0`이면 옆모습 고정).

플레이어 저장 데이터(`profile.ts`), 공용 집어 환경(`grounds.ts`), 낚싯대별 시뮬레이션(`fishing.ts`)을 분리했습니다.
Google 계정·닉네임·채팅·접속 인원·온라인 랭킹은 Firebase에 연결했습니다. 다른 플레이어의 3D 캐릭터가 보이는 멀티플레이는 아직 연결하지 않았습니다.

## 플레이 흐름

러시안 피싱 4를 참고한 복셀 찌낚시입니다. 플레이어당 사용할 수 있는 낚싯대는 손에 든 대를 포함해 총 3대입니다.
E로 대를 손에 들고 캐스팅 → E로 거치대에 놓기 → 입질하면 E 또는 1·2·3으로 다시 집어 들기 → 좌클릭/우클릭/Space로 챔질 → 좌클릭을 눌러 끌어오기.
다른 좌대로 이동할 때는 먼저 들고 있는 대를 거치합니다. F 또는 가방의 회수 버튼으로 대를 가방에 넣으면 사용 자리가 다시 생깁니다.
좌대마다 받침틀이 하나 있고, 세 대는 0.6m 간격으로 일자로 나란히 걸려 모두 정면을 향합니다.
가방의 떡밥 재료 탭에서 미강·옥수수가루·새우분·어분·글루텐분을 확인하고 집어 떡밥과 바늘용 떡밥을 만들 수 있습니다. 재료는 상점에서 묶음으로 구매합니다.
