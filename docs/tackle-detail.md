# 용도별 채비와 하중

모든 하중·굵기·늘어남·조과 계수는 게임 설정이다. 실제 제조사 제품의 보증 규격으로 사용하지 않는다.

## 원줄

모노(나일론), 카본, 합사(PE)를 명시한다. `lineMaterials.ts`의 늘어남은 파이팅 중 원줄 스프링 계산에, 수중 노출과 뻣뻣함은 입질·예민함 계산에 적용한다. 합사는 덜 늘어나지만 충격 완충이 작고, 카본은 수중 노출을 낮추는 대신 뻣뻣함을 반영한다.

재질의 일반적 차이는 [시마노의 모노·카본·합사 설명](https://fish.shimano.com/en-AU/content/c/Articles/product-articles/fluorocarbon-or-mono--which-leader-should-i-use-.html)과 [시가 FAQ](https://seaguar.com/pages/faqs)를 참고했다. 특정 제품의 실제 신율을 그대로 넣은 것은 아니다.

신규 원줄은 카본 6종·합사 6종이며 기존 저장 인덱스 뒤에 붙인다. 카본은 최대 42kgf, 합사는 최대 45kgf다. 기존 가는 줄을 고하중 줄로 일괄 변경하지 않는다.

## 낚싯대와 바늘

- 연안 단대·장거리·연질 완충·초대물 강공 낚싯대를 각 2종 추가했다.
- 기준 하중은 휨과 힘 전달의 기준, 파손 하중은 기준 하중의 1.25배다. 최상위 강공대 기준 32kgf, 파손 40kgf. 현재 마모는 실제 사용 수치에 반영된다.
- 철심 계열 기준 하중은 6/11/20/30kgf, 최상위 파손 하중 37.5kgf다.
- 바늘 16종은 가는축·둥근강축·긴축·광폭으로 나누고 축 굵기·미늘·날카로움을 별도 지정한다. 굵은 축은 박힘, 형태는 입 크기와의 적합성, 미늘은 유지와 느슨한 줄에서의 이탈에 영향을 준다.
- 동일 실존 모델의 호수별 품질과 날카로움은 동일하다. 크기에 따른 폭·하중·입과 미끼의 적합성을 다르게 계산한다. 품질 색상을 날카로움이나 하중 배수로 사용하지 않는다.
- 큰 물고기가 걸렸다는 이유로 약한 바늘의 하중을 자동으로 올리던 보정은 제거했다.

최대 잉어(약 22.7kg)의 초기 돌진 설정은 약 25.4kgf다. 새 대물 낚싯대·원줄·강축바늘 조합에 대응 하중을 마련했다. 이는 포획 성공을 보장하는 수치가 아니며 마모·챔질·장력·미끼 적합성과 플레이에 따라 달라진다.

상점·가방·채비 창에서 같은 규격과 단위를 사용한다. 물고기 무게·뜰채 한도는 kg, 원줄·낚싯대·바늘 힘은 kgf다.
