# 바늘 제품과 호수

바늘은 브랜드 → 제품 모델 → 호수로 나눈다. 모델 ID로 묶으며 이름에서 호수를 지워 묶지 않는다. 기존 45개 장비 ID는 유지한다.

40개 모델에 총 120개 호수 옵션을 제공한다. 소담은 입문·실속, 정호는 규격과 균형, 날끝은 세축·무미늘과 끝 연마, 강턱은 둥근강축·긴축·대물 하중, 백운은 강화 소재와 수제 연마를 맡는다. 브랜드는 모델에 명시하므로 호수가 커지거나 하중이 달라져도 바뀌지 않는다.

같은 모델의 모든 호수는 품질, 가격, 해금 레벨, 날카로움, 형태, 미늘 여부가 같다. 호수에 따라 폭, 축 굵기, 하중, 미끼와 물고기 입에 맞는 정도만 달라진다. 크기가 커진다고 고급 제품이 되지 않는다.

기본·단조·정밀·수제는 호수가 아니라 별도 모델이다. 같은 크기에서도 소재 보강에 따른 하중과 끝 가공에 따른 날카로움이 다르며 모델 설명과 비교 수치로 가격의 이유를 보여 준다. 품질 등급 자체를 별도 성능 배수로 쓰지 않는다.

기존 붕어 무미늘 제품의 4·7호 가격은 90원으로, 균형 둥근축 제품의 5·7·9·10·13호 가격은 160원으로 통일했다. 기존 바늘의 폭·축·하중·흡입 성능은 유지한다. 추가 호수의 수치는 게임 규격이며 기존 호수 사이에서는 보간하고, 단일 규격 모델은 폭과 축 단면을 기준으로 설정한다.

상점은 모델별 카드와 모델별 가격을 표시한다. 상세에서는 한 가지 품질을 제품 상단에 표시하고 호수별 실제 규격과 구매 버튼을 보여 준다. 브랜드 필터의 개수도 호수 개수가 아니라 제품 모델 개수다.

`npm run test:hooks`로 모델의 품질·가격 일관성, 호수 중복, 크기별 하중, 제품 카드·상세·브랜드·품질 필터, 개별 호수 구매와 저장 복원을 검증한다.
