# 개인 목표와 상점 품질

## 상점

- 게임 품질은 기본 → 실용 → 고급 → 전문 → 명품이다. 실존 브랜드 제품에 대한 실제 품질 평가는 아니다.
- 버들못 자체 게임 장비 24종: 낚싯대 4, 원줄 5, 바늘 5, 찌 4, 뜰채 3, 살림망 3.
- 기존 실존 브랜드 상품과 저장 ID, 원줄 배열의 기존 순서는 유지한다.
- 연질 붕어대는 충격 흡수, 가는 원줄·작은 바늘은 예민한 채비, 굵은 줄·강축 바늘은 대물 하중에 적합하다. 고품질이 모든 상황의 최적 장비를 뜻하지 않는다.
- 상점과 가방에서 품질·용도, 상점에서 가격·규격·미끼 및 재료의 단위 가격을 표시한다.
- 기본 낚싯대와 기본 원줄 1.5호·2호는 무료 정비한다. 지렁이가 없고 기본 팩을 구매할 돈이 부족하면 상점에서 5개를 채집할 수 있다.

## 개인 목표 (Q)

- 첫걸음 3개: 첫 포획, 첫 판매, 유료 장비 첫 구매.
- 어종별 36개: 9종 각각 첫 포획, 대물, 초대물, 전설급.
- 낚시터 도감 4개: 각 맵에 실제 출현하는 어종을 모은다. 미개방 낚시터 목표는 잠긴다.
- 기록 3개: 첫 포획 이후 어종별 최고 길이 갱신 1·5·15회.
- 채비 도전 2개: 지렁이로 3종, 기본 낚싯대로 대물 붕어.
- 목표 보상은 저장된 수령 ID로 한 번만 지급한다. 기존 조과로 목표를 복원하며 기존 의뢰·업적과 함께 제공한다.
- 새 조과에 사용한 채비를 저장한다. 구버전 조과에 없는 채비 정보는 추측해 도전을 완료시키지 않는다.

## 조과 처리

- 판매하면 돈, 방생하면 기본 포획 경험치에 20% 보너스. 살림망에서 나중에 방생해도 총 경험치는 동일하다.
- 기존 교란종 처리 규칙은 유지한다. 즉시 수매와 살림망에서 수매하는 경우의 경험치도 동일하다.
- 같은 조과 ID의 중복 기록, 이미 판매·방생한 조과의 재처리, 같은 목표의 반복 보상 수령을 방지한다.
- 진행 데이터는 기존 로컬 저장 방식을 사용한다. 이번 패치는 서버 권위의 경제 시스템을 추가하지 않는다.

관련 구현: `src/game/personalGoals.ts`, `profile.ts`, `itemQuality.ts`, `data.ts`, `items.ts`, `src/ui/panels.ts`.

## 추가 확장: 저축과 장비 성장

- 앞선 24종에 이어 장비 72종을 추가했다. 낚싯대·원줄·바늘 각 16종, 찌 12종, 뜰채·살림망 각 6종이다.
- 낚싯대는 소담(연안 붕어), 원경(장거리), 철심(대물), 가온(균형) 계열을 입문·개량·정밀·명장 4단계로 구성한다. 같은 계열 안에서는 상위 단계가 실제 성능을 개선한다.
- 새 장비 가격은 100~28,500원, 해금은 레벨 1~12다. 기존 상품 가격과 보유 장비는 유지한다.
- 자체 미끼·떡밥 35종: 지렁이, 새우, 옥수수, 곡물떡밥, 글루텐, 어분떡밥, 집어떡밥 7계열에 각 5품질을 제공한다. 기존 실존 브랜드 제품도 유지한다.
- 미끼마다 어종별 선호 배율을 적용한다. 최고 품질도 모든 어종의 입질을 늘리지 않는다. 집어떡밥은 배합 맛과 어종 선호가 실제 집어 계산에 들어간다.
- 품질 필터와 구매 가능한 상품 필터를 제공한다. 상품을 구매 목표로 지정하면 상점에서 저축 진행률·부족 금액·해금 레벨을 볼 수 있다. 목표는 저장되며 해당 상품을 구매하면 해제된다.
- 일반 미끼와 개별 상품의 재고를 구분한다. 일반 미끼가 소진됐다고 고가 상품을 자동으로 대신 소모하지 않는다.

확장 데이터: `src/game/gearExpansion.ts`, `src/game/baitExpansion.ts`.
