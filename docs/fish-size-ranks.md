# 물고기 크기 등급

모든 어종에 **일반 → 준대물 → 대물 → 초대물 → 전설급**을 사용한다. 이름은 같고 길이 기준만 어종마다 다르다. 아래 길이 이상이면 해당 등급이며, 준대물 미만은 일반이다. 월척·4짜·5짜·미터급은 별도 크기 등급명으로 표시하지 않는다.

| 어종 | 준대물 | 대물 | 초대물 | 전설급 | 게임 최대 체장 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 붕어 | 27cm | 30.3cm | 40cm | 50cm | 55cm |
| 잉어 | 65cm | 80cm | 100cm | 105cm | 110cm |
| 향어 | 60cm | 75cm | 85cm | 88cm | 90cm |
| 메기 | 65cm | 90cm | 100cm | 110cm | 115cm |
| 동자개 | 28cm | 35cm | 38cm | 40cm | 42cm |
| 가물치 | 75cm | 90cm | 100cm | 105cm | 110cm |
| 쏘가리 | 45cm | 55cm | 60cm | 63cm | 65cm |
| 배스 | 45cm | 55cm | 60cm | 63cm | 65cm |
| 블루길 | 18cm | 20cm | 23cm | 24cm | 25cm |

게임 등급 기준이며 실제 어종별 공인 등급이나 최대어 기록을 뜻하지 않는다. 붕어의 대물 30.3cm와 상위 40·50cm 문턱은 기존 낚시 호칭의 길이를 참고하되 표시 이름은 공통 용어로 통일했다. 실제 호칭 참고: [낚시춘추의 길이 단위 설명](https://fishingseasons.co.kr/contents_view_detail.asp?b_no=13550), [50cm 붕어 보도](https://m.fishingseasons.co.kr/news_Detail.asp?b_no=15444).

기준은 `src/game/sizeRanks.ts` 한 곳에서 관리하고 어종 데이터가 이를 참조한다. 잡은 물고기 화면·살림망·개인 기록·온라인 랭킹은 저장된 예전 호칭 대신 길이로 현재 등급을 계산한다. 도감은 작은 등급부터 순서대로 기준을 보여준다. 미발견 어종은 기존처럼 이름과 기준을 숨긴다.

5단계가 모두 잡을 수 있는 범위 안에 있도록 붕어 최대 체장은 46→55cm, 잉어는 98→110cm로 확장했다. 기존 중앙값과 퍼짐은 유지하므로 대물이 쉽게 나오도록 확률을 올리지 않는다. 붕어 온라인 기록의 서버 상한도 55cm로 맞췄다. 판매가는 기존 등급별 길이 보너스와 연동된다.

기존 업적 ID `wolchuk`는 진행 기록을 유지하고 표시 이름만 `첫 붕어 대물`로 변경한다.
